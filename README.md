# 🎬 Catálogo de Filmes

Aplicativo mobile e web desenvolvido em **React Native** com **Expo**, exibindo uma lista responsiva com os melhores lançamentos do cinema em 2026. 

## 📱 Sobre o projeto

O app apresenta uma interface que se adapta automaticamente a telas de celular e computador, listando filmes com capas, sinopses, avaliações e preços de aluguel. 

## 🛠️ Tecnologias utilizadas

- React Native & Expo
- JavaScript
- Componentes Nativos: `View`, `Text`, `Image`, `FlatList`, `StyleSheet`
- `useWindowDimensions` para responsividade e layout dinâmico

## 🚀 Como rodar o projeto (Foco Web)

Para executar esta aplicação diretamente no seu navegador, é necessário ter o [Node.js](https://nodejs.org/) instalado no computador.

```bash

# Instale as dependências
npm install

# Rode o projeto
npx expo start
```
